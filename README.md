# Nontapat Wongpatarajitkul · Portfolio

Personal portfolio built with Next.js 16 (App Router), React 19 and TypeScript.

- `/` work gallery, side projects, recognition and contact
- `/case-studies/baojai` and `/case-studies/scai-security` case studies

## Editing content

- `src/content/site.ts`: home page copy, work cards, side projects, recognition, contact
- `src/content/caseStudies.ts`: case study pages
- `public/images/`: screenshots and photos
- `public/Nontapat-Wongpatarajitkul-Resume.pdf`: the resume linked from the nav

## Development

```bash
npm install
npm run dev      # http://localhost:3000
npm run lint
npm run build
```
